# barclay-woods media

Drop images and video for this project here. Anything in this folder is served
from `/portfolio/barclay-woods/<filename>`.

The empty slots on the live page show the exact filename each one expects —
match it, then replace the `slot(...)` call with a real media object. See
`public/portfolio/README.md` for the full reference.

## Planned assets

`MANIFEST.md` (human-readable) and `media.manifest.json` (machine-readable)
record the media this case study will use, what each asset demonstrates, and
the story beat it serves.

Expected files — lowercase, hyphenated, `barclay-*` prefix:

| Filename | Beat | Status |
|---|---|---|
| `barclay-home.png` | Hero | source needed |
| `barclay-community-chat.png` | Role-based platform + Communication | source needed |
| `barclay-operations.png` | Community operations | source needed |
| `barclay-payments.png` | Household finances | source needed |
| `barclay-calendar.png` | Community coordination | source needed |
| `barclay-demo.mp4` (+ `barclay-demo-poster.jpg`) | Live implementation | source unconfirmed |

Drop original full-resolution exports straight in — do not crop, scale, or edit
the UI inside them.
